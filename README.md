# Sistema de análise de notas
Este é um programa que lê a nota final de até 50 estudantes e calcula a média da turma, quantas pessoas ficaram acima dessa média, qual foi a maior nota da turma e o percentual da turma que ficou acima da média da mesma.
Para o funcionamento adequado, o programa está dividido em 4 funções onde nas três primeiras funções temos os cálculos da média da turma, quantas pessoas ficaram acima dessa média e qual foi a maior nota dessa turma. Logo após essas funções, nós temos a função main que é a principal função do sistema, fazendo com que nessa função se tenha a pergunta do sistema para o usuário de quantos estudantes essa pessoa tem, sendo que o usuário tem que digitar um número 1 e 50, dando erro caso não seja um número entre esse intervalo e repetindo para a pessoa digitar um número válido até que o usuário digite o mesmo. Além disso, o mesmo mecanismo também ocorre na verificação da nota, verificando se a nota final está entre 0.0 e 10.0 e repetindo até o usuário digitar um número válido.
Após a entrada de todas as notas, o sistema irá chamar as funções de cálculo de média da turma, quantidade de estudantes acima da média e maior nota e vai calcular qual foi o percentual de estudantes que ficaram acima da média da turma. Finalizando, o sistema mostra todos esses dados para o usuário.
